# Lost Currents

A 3D arcade racing and fishing game built with Three.js and TypeScript.

## Features

- **Racing Mode** - Race 15 unique boats across 3 tiers (Speed, Handling, Acceleration) against AI opponents on a track with boosts and ramps
- **Free Roam** - Explore an open ocean with islands, drive boats, walk on deck, scuba dive, and fish
- **Fishing** - Catch fish with a mashing mechanic, collect underwater loot, and fill your tank to grind for coins
- **Fish Dex** - Track your catches and aim for 100% completion
- **Bait & Tackle Shop** - Buy fishing rods and boat upgrades with earned coins
- **Achievements** - Unlock achievements for various challenges
- **Iron Lung** - A secret horror mode with a submarine, X-ray camera, and monster encounters

## Controls

| Action | Key |
|--------|-----|
| Steer | WASD / Arrow Keys |
| Turbo | Space |
| Stand / Walk | E |
| Dive | G |
| Fish | F |
| Shop | B |
| Fish Dex | T |
| POV Toggle | V |
| Look Around | Mouse (click to lock) |

## Getting Started

```bash
npm install
npm run dev
```
